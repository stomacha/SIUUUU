# 행성 상상도 프롬프트 생성기

행성의 물리량(종류, 질량, 반지름, 지표면 온도, 대기압, 대기 성분, 지각 암석, 물, 모항성, 궤도 등)을 입력하면
**지표면 상상도**와 **우주에서 본 외부 상상도**용 이미지 생성 프롬프트를 만들어 주는 단일 HTML 페이지입니다.

- API 키가 필요 없습니다. 모든 계산과 문장 조립은 브라우저 안에서만 돌아갑니다.
- 생성된 영어 프롬프트를 복사해 Midjourney, DALL-E, Bing Image Creator, Stable Diffusion 등 아무 이미지 생성기에 붙여 넣으면 됩니다.

## 사용법

`index.html`을 브라우저로 열면 끝입니다. 서버나 설치가 필요 없습니다.

1. 상단의 예시 버튼(지구, 화성, 금성, 타이탄형, 적색왜성 조석고정, 뜨거운 목성, 용암 슈퍼지구, 얼음 거성)으로 시작하거나 직접 값을 입력합니다.
   - 대기 성분은 기본 18종 외에 "+ 성분 직접 추가" 버튼으로 이름과 비율을 자유롭게 넣을 수 있습니다. 합계가 100%가 아니면 자동으로 정규화합니다.
   - 행성 종류, 지각, 지질 활동, 생명, 모항성, 화풍, 시점 드롭다운에는 "직접 입력…" 항목이 있어 목록에 없는 값을 자유롭게 적을 수 있습니다. 적은 내용은 프롬프트에 그대로 들어갑니다.
2. 오른쪽에 파생 수치(표면 중력, 밀도, 탈출 속도, 항성 겉보기 크기, 물 끓는점, 거주 가능성 점수)와 물리적으로 어색한 조합에 대한 경고가 표시됩니다.
3. 지표면 프롬프트, 외부 프롬프트, 제외 요소(네거티브 프롬프트)를 각각 복사 버튼으로 복사합니다.

## 입력값이 프롬프트에 반영되는 방식

| 입력 | 영향 |
| --- | --- |
| 질량 / 반지름 | 표면 중력 → 지형의 높이와 형태 (저중력은 길쭉한 기둥, 고중력은 납작한 지형) |
| 지표면 온도 | 용암 바다, 그을린 땅, 온대, 영구동토, 질소·메탄 서리 등 지형 묘사 |
| 대기압 + 대기 성분 (기본 18종 + 직접 추가) | 프롬프트의 대기 조성 문장, 하늘 색과 안개 (CO2 두꺼우면 황적색, 메탄+질소는 주황 안개, 진공이면 낮에도 별이 보임), 외부에서 본 대기 테두리 빛 |
| 모항성 분광형 + 공전 거리 | 빛의 색과 그림자, 하늘에 보이는 항성의 겉보기 크기 |
| 조석 고정 | 영원한 일몰 지대, 낮밤 경계선, 주야 반구 간 바람 |
| 액체 물 피복률 / 얼음 피복률 (별도 입력) | 바다·호수와 빙관·빙하·얼음 지각을 따로 묘사. 기타 표면 액체(예: 액체 메탄 호수)는 자유 입력 |
| 구름, 지질 활동, 자기장, 위성, 고리, 생명 | 날씨, 화산, 오로라, 하늘의 위성, 고리, 식생이나 도시 |

## 나중에 이미지까지 자동으로 만들고 싶다면

프롬프트 생성 로직(`build` 함수)은 이미지 생성과 분리되어 있으므로, 원하면 다음 중 하나를 붙일 수 있습니다.

- 로컬 Stable Diffusion / ComfyUI (API 키 불필요, GPU 필요)
